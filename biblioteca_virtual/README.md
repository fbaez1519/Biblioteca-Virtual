# 📚 Biblioteca Virtual

Sistema de gestión bibliotecaria desarrollado con PHP, MySQL, HTML, CSS y JavaScript.

## 🚀 Características

- ✅ Sistema de autenticación (login/registro)
- ✅ Gestión de usuarios y roles (Admin, Bibliotecario, Usuario)
- ✅ CRUD completo de recursos (libros, audiolibros, artículos)
- ✅ Sistema de préstamos y devoluciones
- ✅ Panel de administración
- ✅ Perfil de usuario
- ✅ Diseño responsive y moderno
- ✅ Colores pastel y experiencia agradable

## 📋 Requisitos

- XAMPP 7.4+ o superior
- PHP 7.4+
- MySQL 5.7+
- Navegador moderno

## 🔧 Instalación

1. Clona o descarga el proyecto en `C:\xampp\htdocs\biblioteca_virtual\`
2. Abre phpMyAdmin: `http://localhost:8080/phpmyadmin`
3. Crea la base de datos `biblioteca_virtual`
4. Importa el script SQL proporcionado
5. Inicia Apache y MySQL en XAMPP
6. Accede a: `http://localhost:8080/biblioteca_virtual/`
